# Phase 16–19 Interactive Release

## Phase 16

DeepSeek JSON Output converts free-form requests and revisions into strict Pydantic schemas. Missing hard constraints produce clarification questions. Provider or schema failures fall back to deterministic parsers. A grounded explainer can narrate only validated plan facts.

The Web UI renders concrete attractions, times, route legs, admissions, transport, lodging, budget, freshness, and source metadata.

## Phase 17

The planning workbench supports multiple conversational revisions, explicit transport/lodging locks, direct attraction replacement, structured diffs, version history, and undo. Replanning continues to reuse the frozen catalog.

## Phase 18

The UI includes a network-free SVG itinerary map, budget composition bars, provenance inventory, model/Token counters, provider fetch count, local replan count, and an event timeline.

## Phase 19

Three deterministic demo scenarios, no-key offline mode, API/UI integration tests, frontend syntax checks, CI evaluation, demo instructions, and a release checklist make the repository suitable for repeatable portfolio demonstrations.
