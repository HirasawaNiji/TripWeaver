# Phase 10：评测与 API 交付

## 固定评测集

`tripweaver evaluate` 运行 40 组固定北京—上海需求，覆盖人数、日期、天数、兴趣、交通偏好、正常预算和预期不可行预算。

指标包括：

- 预期结果准确率
- 硬约束满足率
- 不可行方案比例
- 来源元数据完整率
- 同输入重复运行稳定性
- 平均本地规划延迟
- Token 成本（当前确定性链路为 0）

这是 Fixture 基线，不应与外部 MCP 可用率混为一谈。实时评测需要在固定观察窗口内另行运行。

## FastAPI

- `GET /health`
- `POST /v1/plans/fixture`
- `POST /v1/agent/runs`
- `GET /v1/metrics`

API 仍是查询与规划接口，不包含身份认证、支付、预订或订单写入。公网部署前必须增加认证、请求限速、HTTPS、审计和密钥托管。
