# Phase 7：住宿区域与酒店候选

## 目标

在没有授权 OTA 房价接口的前提下，让住宿位置真实、价格口径诚实，并让住宿选择进入确定性通勤与预算计算。

## 数据边界

- 高德提供酒店 POI、名称、地址、评分、位置和市内路线。
- `LODGING_NIGHTLY_PRICE_CNY` 可提供用户自行确认的每晚价格。
- 未提供价格时，TripWeaver 按评分使用固定档位估算。
- 所有住宿价格来源状态均为 `ESTIMATED`，因为系统无法验证实时房型、税费和可订状态。
- 高德 `average_cost` 不作为酒店房价使用。

## 选择方法

候选酒店先按与核心景点几何中心的距离、评分和稳定 ID 排序。随后 Planner 使用“每晚价格 + 到核心景点的通勤分钟惩罚”选择住宿锚点。路线查询在 Snapshot 阶段完成，规划循环不访问网络。

单个酒店详情失败会从候选移除；全部酒店失败则仅住宿部分回退 Fixture。
